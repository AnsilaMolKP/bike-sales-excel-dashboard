# 🚴 Bike Sales Dashboard - Excel Project

## 📌 Overview
This project analyzes bike sales data to identify customer purchasing behavior and key influencing factors such as income, age, and commute distance.

---

## 📊 Dashboard Features
- Interactive dashboard using slicers
- Analysis based on:
  - Gender
  - Age Brackets
  - Income
  - Commute Distance
  - Region & Education

---

## 🛠 Tools Used
- Microsoft Excel
- Pivot Tables & Pivot Charts
- Data Cleaning
- Slicers & Dashboard Design

---

## 📈 Key Insights
- Higher income customers are more likely to purchase bikes  
- Middle-aged customers show higher purchase trends  
- Customers with shorter commute distances tend to buy more bikes  
- Purchase behavior varies across gender and regions
